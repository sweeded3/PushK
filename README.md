# Пушистый Контур — готовый сайт

Готовая Astro-версия лендинга для GitHub Pages.

## Как загрузить в GitHub

1. Распакуйте ZIP.
2. В репозитории `sweeded3/PushK` замените файлы содержимым этой папки.
3. Проверьте, что есть файлы:
   - `package.json`
   - `astro.config.mjs`
   - `src/pages/index.astro`
   - `src/styles/global.css`
   - `public/assets/logo-wide.png`
   - `.github/workflows/deploy.yml`
4. Сделайте Commit changes.
5. Вкладка Actions → дождаться зелёной галочки.
6. Открыть: `https://sweeded3.github.io/PushK/`

## Что уже включено

- новый широкий логотип;
- hero/head с изображением до/после;
- бейджи Яндекс Хорошее место 2025/2026;
- услуги на реальных фото;
- промо-баннер с пуделем и оранжевой кнопкой;
- блок до/после;
- блок преимуществ;
- визуальный модуль отзывов в стиле Яндекс;
- контакты и footer;
